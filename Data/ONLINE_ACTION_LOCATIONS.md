# Online action location review

Reviewed the 25 missing scheduled quest actions against public Forever quest,
item, creature and object pages. The evidence and source URLs are retained in
`ONLINE_ACTION_LOCATIONS.json`; the generated locations are consumed through
the shared action-location resolver.

22 actions now have sourced locations. The three actions for quest 912,
Stonesplinter Trogg Disguise, were removed from the playable guide because no
usable start, objective or return location could be established. Its reference
record remains available for research. The route audit baseline excludes these
same three actions, so its preservation check covers the revised playable route.

Coordinates are approximate observations, not guaranteed live spawn positions.
Some exploration entrances use explicitly identified inherited Classic or
community evidence. Item pickups, collection areas, portal access and fishing
waters retain their actual action roles rather than borrowing a quest-giver
location. The source JSON records these distinctions.
