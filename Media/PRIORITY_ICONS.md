Guide markers use transparent TGA assets (32x32 critical, 64x64 reward markers) generated by
`tools/build_priority_icons.py`. Each inline marker receives the same size as
the quest Accept / Turn-in icon and scales with the guide font setting.

- Inverted gold triangle with a dark brown exclamation mark: key / critical.
  Colors match map pins (#ECBB31 gold, #381F09 dark brown).
  Catch-up preserves it; manual Skip is allowed.
- Native portrait combat crossed swords (`Interface\\CharacterFrame\\UI-StateIcon`,
  top-right cell, matching `PlayerAttackIcon`): equipment reward.
- Overlapping gold, silver and bronze coins: money reward.
- Non-key actions have no generic optional marker.

Set `optionalBenefit="money"` on an authored action to specify money as its
purpose; positive `rewardMoney` also selects coins. Gear uses `GearRewards.lua`:
uncommon or better equipment, class/level compatibility and live proficiency,
then a class-weighted stat/DPS score that must beat current equipment by at
least 10% and one point. Rings/trinkets compare either slot; two-handers compare
the equipped main-hand and off-hand together. This is a conservative leveling
estimate, not a spec-specific best-in-slot recommendation. Missing item or
equipped-item data hides the marker until it loads. Equipment, skill and item
data events refresh it. Reward notes can set `gearQuestIDs` to reference quests
whose rewards should be evaluated; a `gear` label alone never forces an icon.
Unknown rewards have no marker. Critical status wins over
reward markers. Markers follow the action title, including collapsed side actions.
